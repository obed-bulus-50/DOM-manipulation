Dynamic Paragraph Creator

How it works: HTML: A button (Add Paragraph) triggers the creation of a new paragraph. A container
holds all generated paragraphs. JavaScript: Uses an event listener on the button. Each click increments a counter and creates a new

element. The paragraph is appended to the container. Styling: Simple CSS for better readability. If you want, I can extend this so the user can type custom text and have that appear in the new paragraph instead of auto-numbering. Do you want me to make that version?
