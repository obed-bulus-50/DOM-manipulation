JavaScript setAttribute() & getAttribute() Demo

How It Works: setAttribute(name, value) Changes or adds an attribute to an element. In the example, it changes the src and alt attributes of the tag. getAttribute(name) Retrieves the value of a specified attribute. In the example, it reads the alt text of the image.
